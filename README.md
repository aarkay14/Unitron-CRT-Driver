# Unitron-CRT-Driver
A universal CRT driver PCB inspired by the widely used “China TV Kit” mainboards, commonly found in low-cost CRT television repairs and retro hardware restoration.

This project aims to recreate, document, and improve upon designs based on chipsets such as TMPA889X, which integrate video decoding, synchronization, and signal processing into a single solution for analog CRT displays.

These universal CRT boards serve as the central processing unit of a television, handling composite/RF input decoding, luminance and chrominance separation, audio processing, and coordination with deflection circuits to generate a stable image on a CRT tube.

Originally developed for cost-effective mass repair and reuse of CRT tubes, such boards are widely used in regions where CRT televisions remain in service, as well as by hobbyists and retro gaming enthusiasts seeking analog display solutions.

This repository focuses on reverse engineering, recreating schematics, and building an open and well-documented alternative to these generic designs, with the goal of preserving CRT technology and enabling high-quality, reproducible hardware for the community.

Project Goals:
1. Collect as detailed as possible information to recreate a TMPA889X-based universal CRT PCB
2. Provide complete documentation and gerber files to build your own board
3. Improve design quality and reliability over generic kits
4. Enable input ports for S-Video / Component and Composite
5. Build an open hardware reference for future CRT projects
